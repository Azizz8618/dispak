# pascal-arfa — монитор зашифрованных областей архива АРФА

Полный цикл работы с **зашифрованными областями архива АРФА** из программы
на Паскале (Паскаль-Монитор МС «Дубна»):

* `C ном длн` — создание области (Э63 01, слово «КЛЮЧАР» на СМ);
* `W ном слв` — шифрование образца ГОСТ 28147-89 (библиотека GOSTLIB,
  режим CTR) и запись в зону 0 области (Э63 12 + Э70);
* `R ном слв` — чтение зоны 0 (Э70), расшифрование, печать и сверка текста;
* `I ном` — сведения об области (Э63 07);
* `D ном` — уничтожение области (Э63 02).

Области именуются по-старому (9 букв ГОСТ + шифр хозяина):
1 — ТЕКСТ, 2 — СЕКРЕТ, 3 — АРХИВ, 4 — ОБЛАСТ.

Том архива — `2196` (прилагается, каталог пуст). Деку первых двух
карт `D 1`/`D 2` задача сама чистит остатки прежних прогонов,
поэтому вывод повторяем от запуска к запуску.

## Том 2348 (Паскаль + GOSTLIB)

Деку нужны Паскаль-система и библиотека ГОСТ со тома 2348
(см. проект besm-crypto, файл `disk2348`; там же история его сборки:
Pascal Compiler 15.1 в PERSO с зоны 02030, GOSTLIB с зоны 02560,
runtime с зоны 02000). Том в репозиторий не входит из-за размера.
Перед прогоном положите его в путь поиска образов:

```sh
cp /путь/к/besm-crypto/disk2348 ../../build/dispak/2348
python3 ../run-test.py
```

(или в сам каталог теста — `--path=.:../../build/dispak` находит оба места).

## Технические заметки

* Ответы Э63 снимаются с СМ (дозаказ — лог.номер) и М16 (код ответа).
  Для канонической целой формы Паскаля значения проходят через поля
  упакованных записей (`w2`), иначе сравнение `code = 0` с константой
  из пула констант ложно.
* АИСП передаётся через индекс-регистр М6 (`ati 6`, `Э63 (6)`),
  РМР устанавливается командой `aex (5)` по адресу в М5. Регистры
  М1, М2, М7-М17 заняты кодогенератором компилятора.
* Слова текста шифруются половинками по 24 разряда: «сырые» 48-разрядные
  слова в арифметике библиотеки ГОСТ не нормализуются.
* Буферные листы обмена Э70 — страницы 010-013 (адреса 020000-027777).
