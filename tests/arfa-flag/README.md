# arfa-flag — признак архивного тома (Э50 0166)

Том `2296` размечен `besmtool arfa-format`: паспорт (зона 0) с признаком
архивного тома (слово 0007, байт 4 = 02) и пустым каталогом АРФЫ.

Программа на автокоде проверяет:

1. `Э50 0166` с И15=2 (запрос признака) — ожидается СМ=1;
2. И15=1 (уничтожить) — запрос даёт СМ=0;
3. И15=0 (занести) — запрос даёт СМ=1;
4. подключение тома целиком (`Э50 0131`, лог.номер 030) — СМ=0 (подключён);
5. чтение зоны 1 тома через Э70 — **отказ**: ошибка 34 («ОШ.В ИНФ.СЛ.ЭКСТ»),
   перехваченная обработчиком (Э50 0102/0103) и напечатанная как res5.

Печать res1..res5 идёт через Э64 одним восьмеричным списком:
ожидается `...0001  ...0000  ...0001  ...0000  ...0034`.

Аналог в реальном ДИСПАКе — сервисная программа УСТСНЯ (руководство
системного программиста, п. 8.6.1): признак архивного диска «защищает том
от прямого обращения экстракодом обмена», чем делает том невидимым в СЕРПе.
