# Навыки для проекта ДИСПАК

Все навыки хранятся ГЛОБАЛЬНО в `~/.cline/skills/`.
Локальная директория `.cline/skills/` содержит симлинки на SKILL.md.

## Доступные навыки

| Навык | Назначение |
|-------|------------|
| `dispak-commands` | Команды и экстракоды БЭСМ-6 |
| `dispak-modules` | Модули ОС Диспак (БЕМШ) |
| `dispak-tracer` | Трассировка экстракодов |
| `bemsh-analyzer` | Анализ исходников БЕМШ |
| `code-map` | Карты кода (сжатие контекста) |
| `disbesm6-disasm` | Дизассемблирование БЭСМ-6 |
| `dtran-disasm` | Транслятор ДИСПАК |
| `madlen-analyzer` | Анализ на МАДЛЕН |
| `small-portions` | Дробление задач (анти-таймаут) |
| `token-saver` | Экономия токенов |
| `init-session` | Инициализация сессии |
| `task-splitter` | Разбиение задач |
