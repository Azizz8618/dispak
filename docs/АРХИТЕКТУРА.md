# Архитектура эмулятора ДИСПАК

## Обзор

Dispak — пакетный эмулятор БЭСМ-6, реализующий интерпретацию команд
и перехват экстракодов. В отличие от аппаратного эмулятора (SIMH BESM6),
dispak работает на уровне ОС: команды БЭСМ-6 интерпретируются,
системные вызовы обрабатываются программно.

## Компоненты

### 1. dispak (ядро эмулятора)

**Точка входа:** `dispak/dispak.c:main()`

**Главный цикл:** `dispak/cu.c`
- `unpack()` — распаковка команды (левая + правая половина слова)
- Цикл: fetch → decode → execute → store
- Экстракоды (код 030-077 в левой команде) → `extra.c`

**Экстракоды:** `dispak/extra.c` (2572 строки)
- `exform()` — формирование вызова экстракода
- Перехват: Э20-Э77 (системные функции ОС)
- Стандартный I/O: Э64 (перехват через intercept_ex)

**Арифметика:** `dispak/arith.c`
- RAU (регистр арифметических операций): нормализация, округление
- RUU (регистр универсальных операций): логические операции

**Кодировки:** `dispak/encoding.c`
- ГОСТ 10859 (6-битный): основная кодировка БЭСМ-6
- KOI-7 (7-битный): для терминалов
- UTF-8: для хост-системы

**Диски:** `dispak/disk.c`
- Формат: бинарные файлы, ZONE_SIZE = 8 + 1024 слов
- Стандартный диск: НОМДИСК 2053
- Путь поиска: `--path=dir1:dir2`

### 2. besmtool (утилита дисков)

Утилита для работы с образами дисков БЭСМ-6:
- `list` — список файлов на диске
- `dump` — дамп содержимого зоны
- `write` — запись файла на диск
- `erase` — удаление файла

### 3. disbesm6 (дизассемблер)

Дизассемблирование бинарников БЭСМ-6:
- Ввод: бинарный файл (словa по 8 байт)
- Вывод: мнемоника команд + адреса + комментарии

## Формат команды БЭСМ-6

```
Левая половина (24 бита)    | Правая половина (24 бита)
[ИР 3 бита][КОД 6][АДРЕС 15] | [ИР 3][КОД 6][АДРЕС 15]
```

- ИР = индекс-регистр (0-17)
- КОД = код операции (00-77)
- АДРЕС = адрес операнда (0-77777₈)

## Экстракоды (detalizatsiya)

Экстракод — команда с кодом 030-077 в левой половине слова.
При исполнении вызывается обработчик ОС (Э20-Э77).

### Основные экстракоды

| Код | Назначение | Реализация в dispak |
|-----|------------|---------------------|
| Э20 | Запрос программы | exform() |
| Э21 | Печать (АЦПУ) | exform() → printer.c |
| Э22 | Чтение (перфокарты) | exform() → input.c |
| Э24 | Диск | exform() → disk.c |
| Э25 | Лента/барабан | exform() |
| Э64 | Стандартный I/O | intercept_ex() |
| Э70-Э77 | НМБ | exform() |

### Перехват Э64

Для стандартного I/O (Э64) dispak использует механизм перехвата:
- `intercept_ex()` — установка ловушки
- При вызове Э64 → проверка intercept_mask → обработка

## Память БЭСМ-6

- Объём: 512K слов (стандарт) или 256K (BESM6_SMALL_DISKS)
- Формат слова: 48 бит (два 24-битных полуслова)
- Адресация: 15 бит (0-77777₈)

## Регистры

| Регистр | Назначение |
|---------|------------|
| СМ (acc) | Сумматор (48 бит) |
| М0-М15 | Индекс-регистры (24 бита) |
| М16 | Адрес возврата |
| М17 | Режим (биты прерываний) |
| РК (pc) | Счётчик команд |
| АСУ | Адрес середины слова |
