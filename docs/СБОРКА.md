# Сборка и тестирование ДИСПАК

## Требования

- **ОС:** Linux (тестировался на ALT Linux)
- **Компилятор:** GCC или Clang (C99)
- **CMake:** ≥ 3.10
- **Библиотеки:** стандартные (libc, libm)

## Сборка

### Полная сборка

```bash
cd ~/Yandex.Disk/dispak
mkdir -p build
cd build
cmake ..
make -j$(nproc)
```

### Установка (опционально)

```bash
sudo make install
# Устанавливает в /usr/local/bin:
#   dispak, besmtool, disbesm6
```

## Тесты

```bash
cd ~/Yandex.Disk/dispak/build
make test
```

**Ожидаемый вывод (текущее состояние):**
```
100% tests passed, 0 tests failed out of 51
```

Ранее «вечные» падения устранены: датарезленные `bemsh-ms`, `forex`,
`serp-ogl-2113` — регенерацией эталонов отправителями (`2bf17f5`);
`librefer-2048/2053`, `stat` — локальной регенерацией эталонов
(натуральный вывод, даты замаскированы `##.##.##` — их отбрасывает
wildcard-механизм `run-test.py` при последующих прогонах).

**Тома тестов** (2196/2296/2348) поставляются в `tests/disks` (2348 — .xz)
и прописываются `run-test.py` автоматически по `disks.txt` — ручного
копирования тома 2348 больше не требуется (тест `pascal-arfa`).

## Диагностика сборки

### Ошибки CMake

```bash
# Проверка версии CMake
cmake --version

# Очистка сборки
rm -rf ~/Yandex.Disk/dispak/build
mkdir ~/Yandex.Disk/dispak/build
```

### Ошибки компиляции

```bash
# Лог сборки
tail -50 /tmp/dispak_build.log

# Одиночная сборка (для отладки)
cd ~/Yandex.Disk/dispak/build
make dispak 2>&1 | head -30
```

## Полезные команды

```bash
# Trасса экстракодов
dispak -t task.txt

# Статистика команд
dispak -s task.txt

# Останов на первой команде
dispak -b task.txt

# Перехват экстракодов
dispak -x task.txt
```
