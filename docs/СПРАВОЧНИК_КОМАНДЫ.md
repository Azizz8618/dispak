# Справочник инструментов пакетного эмулятора БЭСМ-6 (dispak)

Для ИИ-агентов. Основан на исходном коде `~/dispak/`.

---

## 1. Обзор компонентов

| Программа | Назначение | Исходники |
|-----------|-----------|----------|
| **dispak** | Пакетный эмулятор БЭСМ-6 (интерпретатор команд) | `dispak/dispak/` |
| **besmtool** | Утилита управления образами дисков | `dispak/besmtool/` |
| **disbesm6** | Дизассемблер БЭСМ-6 | `dispak/disbesm6/` |

**Важно:** dispak НЕ эмулирует аппаратуру (нет прерываний, таймеров, ДКС, терминалов).
Он интерпретирует команды и перехватывает экстракоды программно.

---

## 2. dispak — пакетный эмулятор

### 2.1. Запуск

```
dispak [опции] <файл-задания>
dispak [опции] <номер-буфера-ввода>
dispak [опции] --decode-output <raw-файл>
```

### 2.2. Опции командной строки

| Опция | Длинная форма | Описание |
|-------|--------------|----------|
| `-h` | `--help` | Справка |
| `-V` | `--version` | Версия |
| `-x` | `--native` | Нативная реализация экстракода E64 |
| `-e` | `--elfun` | Нативная реализация элементарных функций |
| `-b` | `--break` | Останов на первой команде (вход в отладчик) |
| `-v` | `--visual` | Визуальный режим отладчика |
| `-t` | `--trace` | Трассировка экстракодов (повтор=2, тройной=3) |
| | `--trace-e64` | Трассировка только E64 (печать) |
| `-s` | `--stats` | Статистика по машинным командам |
| `-p` | `--output-enable` | Печать на stdout (по умолчанию для batch) |
| `-q` | `--output-disable` | Подавить печать (по умолчанию для TELE) |
| `-o file` | `--output=file` | Печать в файл |
| `-l` | `--output-latin` | Латиница для вывода |
| | `--output-cyrillic` | Кириллица (по умолчанию) |
| | `--output-raw=file` | Сырой дамп вывода |
| | `--decode-output file` | Декодировать сырой вывод |
| `-c file` | `--punch=file` | Перфолента в файл |
| | `--punch-binary` | Перфолента в бинарном формате |
| | `--input-encoding=code` | Кодировка: `utf8`, `koi8`, `cp1251`, `cp866` |
| | `--path=dir1:dir2...` | Путь поиска дисковых образов |
| | `--bootstrap` | Только пользовательский режим (для диска 2099) |
| | `--no-insn-check` | Все слова — команды (кроме addr 0) |
| | `--drum-dump=file` | Дамп барабана 27 |

### 2.3. Примеры запуска

```bash
dispak -p my_task.txt                  # Пакетный вывод на stdout
dispak -o output.txt my_task.txt       # Вывод в файл
dispak -b my_task.txt                  # Вход в отладчик
dispak -t my_task.txt                  # Трассировка экстракодов
dispak -q my_task.txt                  # Без печати
dispak -x -p my_task.txt              # Нативная печать E64
dispak --decode-output raw.bin         # Декодирование сырого вывода
dispak --bootstrap make2099.b6         # Бутстрап системного диска
```

## 3. Формат входного файла задания

### 3.1. Структура файла

```
<паспорт>     — идентификация задачи и ресурсы
<данные>      — программы и данные (S, C, W, N, L, A)
<терминатор>  — "финиш" или "FINISH"
```

### 3.2. Паспорт (обязательные поля)

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
```

| Поле | Пример | Описание |
|------|--------|----------|
| `ШИФР` | `ШИФР 410301^` | Идентификатор (6 или 12 цифр) |
| `ОЗУ` | `ОЗУ 512K^` | Объём памяти (K=1024 слов) |
| `ВХО` | `ВХО 1^` | Количество входов |
| `ВРЕ` | `ВРЕ 001000^` | Лимит CPU (ЧЧММСС) |
| `START` | `START 1000^` | Точка входа (восьмеричная) |
| `PAGE` | `PAGE 1000-1777^` | Диапазоны страниц |
| `PRINT` | `PRINT 7^` | Метры бумаги (по умолч. 7, макс. 64) |
| `TRACT` | `TRACT 10^` | Тракты барабана |
| `TAPE` | `TAPE 30(2053-RW)^` | Лента/диск (NN=30-67_8, -RW) |
| `TELE` | `TELE^` | Интерактивный режим |
| `E` | `E` | Конец паспорта |

### 3.3. Элементы данных (конец — `E`)

| Префикс | Описание | Пример |
|---------|----------|--------|
| `S <адрес>` | Адрес загрузки | `S 1000` |
| `C <9-18 цифр>` | Машинные команды (1-2 на слово) | `C 012 032 1000` |
| `W <до 16 цифр>` | Слово данных | `W 1234567890ABCDEF` |
| `N <число>` | Вещественное число | `N 3.14159` |
| `L <6 символов>` | Литерал ГОСТ | `L HELLO` |
| `A 0/1/2` | Текст (конец `_$`) | |
| `A 3` | Бинарные данные | |

### 3.4. Полный пример

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
S 1000
C 012 032 1000
C 011 031 1001
W 1234567890ABCDEF
E
финиш
```

## 4. Машинные команды БЭСМ-6

### 4.1. Команды с памятью

| Код_8 | Мнемоника | Операция |
|------|-----------|----------|
| 000 | `atx` | СМ → ячейка (запись) |
| 001 | `stx` | Ячейка → СМ (чтение) |
| 002 | `mod` | Модификация (привилегированная) |
| 003 | `xts` | Ячейка → СМ и стек |
| 004 | `a+x` | СМ + ячейка → СМ |
| 005 | `a-x` | СМ - ячейка → СМ |
| 006 | `x-a` | Ячейка - СМ → СМ |
| 007 | `amx` | СМ ↔ ячейка (обмен) |
| 010 | `xta` | Ячейка → СМ |
| 011 | `aax` | СМ ∧ ячейка → СМ (AND) |
| 012 | `aex` | СМ ⊕ ячейка → СМ (XOR) |
| 013 | `arx` | СМ + ячейка + 1 → СМ (+перенос) |
| 014 | `avx` | СМ ∨ ячейка → СМ (OR) |
| 015 | `aox` | СМ ∨ ячейка → СМ (инверсный OR) |
| 016 | `a/x` | СМ / ячейка → СМ (деление) |
| 017 | `a*x` | СМ × ячейка → СМ (умножение) |
| 020 | `apx` | СМ + ячейка → СМ (старшая часть) |
| 021 | `aux` | СМ ∨ ячейка → СМ (дополнит.) |
| 022 | `acx` | СМ + ячейка + 1 → СМ (старш.) |
| 023 | `anx` | СМ ∧ ячейка → СМ (инверсн.) |
| 024 | `e+x` | Мантисса: СМ + ячейка |
| 025 | `e-x` | Мантисса: СМ - ячей��а |
| 026 | `asx` | Арифм. сдвиг СМ по ячейке |
| 027 | `xtr` | Ячейка → СМ (арифм. сдвиг) |
| 030 | `rte` | Ячейка → РМР |
| 031 | `yta` | СМ в特殊 |

### 4.2. Регистровые команды

| Код_8 | Мнемоника | Операция |
|------|-----------|----------|
| 034 | `e+n` | СМ + N → СМ (арифм.) |
| 035 | `e-n` | СМ - N → СМ (арифм.) |
| 036 | `asn` | Арифм. сдвиг СМ на N |
| 037 | `ntr` | N → РМР |
| 040 | `ati` | СМ → индекс-регистр |
| 041 | `sti` | Индекс → СМ |
| 042 | `ita` | Индекс → СМ |
| 043 | `its` | Индекс → СМ и стек |
| 044 | `mtj` | M → J |
| 045 | `m+j` | M + J → J |

### 4.3. Управляющие команды

| Код_8 | Мнемоника | Операция |
|------|-----------|----------|
| 032-033 | `ext` | Экстракод (привилегированная) |
| 046-047 | `x46/x47` | Экстракод (привилегированная) |
| 022 | `utc` | Установить индексный регистр |
| 023 | `wtc` | Запись из РМР |
| 024 | `vtm` | Установить индекс-регистр |
| 025 | `utm` | Изменить индекс-регистр |
| 026 | `uza` | Переход при СМ = 0 |
| 027 | `u1a` | Переход при СМ != 0 |
| 030 | `uj` | Безусловный переход |
| 031 | `vjm` | Переход с записью адреса возврата |
| 032 | `iret` | Возврат из прерывания (привил.) |
| 033 | `stop` | Останов |
| 034 | `vzm` | Переход при СМ = 0 (в регистр) |
| 035 | `v1m` | Переход при СМ != 0 (в регистр) |
| 037 | `vlm` | Уменьшить регистр и перейти |

### 4.4. Формат команды

**Короткая команда** (бит 23 = 0): 10-битный адрес, команда занимает правое полуслово.
**Длинная команда** (бит 23 = 1): 15-битный адрес, команда занимает левое полуслово.

- **R** — номер регистра (0-15)
- **PP** — код операции
- **Адрес** — 13-битный (длинная) или 10-битный (короткая)

## 5. Экстракоды (dispak)

Экстракоды вызываются командами с кодами 050-077 (левое полуслово).
В dispak обрабатываются в `extra.c`.

### 5.1. Э50 — Общего назначения (N в reg[016])

| N_8 | Название | Описание |
|----|----------|----------|
| 000 | arctg | Арктангенс от СМ |
| 010 | get_time | Время с полуночи (такты) |
| 011 | set_handler | Адрес обработчика перехвата |
| 012 | set_emask | Маска событий |
| 013 | disable_async | Запретить асинхронные процессы |
| 014 | enable_async | Разрешить асинхронные процессы |
| 015 | restore_state | Восстановить состояние |
| 017 | wait_events | Ожидание событий (блокировка) |
| 021 | events | Управление событиями |
| 067 | DATE* | Дата (специфика Диспак) |

### 5.2. Э51 — Тригонометрия

- М16 = 0 → sin(СМ)
- М16 != 0 → cos(СМ)

### 5.3. Э53 — Системные вызовы

| N_8 | Описание |
|----|----------|
| 010 | Время с полуночи |
| 011 | Адрес обработчика |
| 012 | Маска событий |
| 013 | Запрет асинхрона |
| 014 | Разрешение асинхрона |
| 015 | Восстановление состояния |
| 017 | Ожидание событий |
| 021 | Управление событиями |

### 5.4. Э62 — Управление системой

| N_8 | Описание |
|----|----------|
| 000 | Безусловное завершение |
| 042 | Очистка потока вывода |
| 044 | Отмена потока вывода |
| 053 | Маска перехвата экстракодов |
| 055 | Адрес обработчика ошибок |
| 0102 | Останов чтения с терминала |
| 0103 | Логический номер консоли |
| 0123 | Включение/отключение перфоленты |
| остальные | Установка смещения тома / закрытие тома |

### 5.5. Э63 — Информация о времени

| N_8 | Описание |
|----|----------|
| 0 | Время до конца решения (float) |
| 1 | Вывод времени счёта |
| 3 | No-op |
| 4 | Время счёта (такты) |

### 5.6. Э64 — Печать

Формат команды: слово управления (CW) в памяти. Функция `print()` в `extra.c`.

**Форматы вывода (старшие биты слова):**

| Код | Формат |
|-----|--------|
| 0, 8 | Текст в кодировке ГОСТ |
| 1, 5, 9, 13 | Машинная команда |
| 2, 10 | Восьмеричное число |
| 3, 11 | Вещественное число |
| 4, 12 | Текст в кодировке ITM |
| 6, 7, 14, 15 | Шестнадцатеричное число |

**Специальные символы ГОСТ:**
- `0201` — новая страница
- `0174/0265` — повтор последнего символа
- `0143/0341` — символ нулевой ширины
- `0200/0201` — установка позиции
- `0231/0300/0377` — конец информации

### 5.7. Э70 — Дисковый ввод-вывод

Слово управления содержит две микроинструкции:
- **Левая:** адрес листа (буфера)
- **Правая:** номер устройства (биты 5-0), адрес зоны/тракта

| Диапазон | Тип |
|----------|-----|
| 030-067 | Диски |
| 0-27_8 | Барабаны (временно хранение) |

### 5.8. Э71 — Терминальный ввод-вывод

| Код операции | Описание |
|-------------|----------|
| 0120 | Статус/освобождение |
| 0220 | Вывод на терминал |
| 010 (любой) | Перфокарты (punch) |

### 5.9. Э72 — Ресурсы

| Тип запроса | Описание |
|------------|----------|
| `KEYE72` | Маска перехвата / адрес выхода |
| `020` | Закрытие ленты/диска |
| `030` | Открытие ленты/диска |

### 5.10. Э74 — Выход из задания

- Если установлен обработчик перехвата — переход на него
- Если задан `exitaddr` — переход на `exitaddr`
- Иначе — завершение (E_TERM)

## 6. Отладчик dispak

Отладчик активируется опцией `-b` или командой `Step`.
Приглашение: `- `

### 6.1. Навигация и управление

| Команда | Описание |
|---------|----------|
| `Quit` | Выход |
| `Help` | Справка |
| `Where` | Текущая команда (PC, инструкция, мнемоника) |
| `Visual` | Вкл/выкл визуальный режим |
| `File` | Имя входного файла |
| `Go` | Продолжить выполнение |
| `Go <адрес>` | Перейти по адресу и продолжить |
| `Step` | Выполнить одну команду |
| `Step N` | Выполнить N команд |
| `Step <адрес>` | Перейти по адресу и выполнить одну |
| `Trace N` | Установить уровень трассировки (0-3) |
| `EC <номер>` | Вкл/выкл останов на экстракоде N_8 |

### 6.2. Осмотр данных

| Команда | Формат | Описание |
|---------|--------|----------|
| `A -` | | СМ в восьмеричном |
| `AD` | | СМ как вещественное (десятичное) |
| `Y -` | | РМР в восьмеричном |
| `R -` | | Все регистры |
| `C -` | | Управляющее слово |
| `RTAG -` | | Теги регистров |
| `I <N> -` | `I 7 -` | Индекс-регистр N |
| `<адрес> -` | `1000 -` | 8 слов (команды) |
| `<адрес> T` | `1000 T` | 8 слов как текст |
| `<адрес> B` | `1000 B` | 8 слов побайтово |
| `<адрес> U` | `1000 U` | 8 слов как символы |
| `<адрес> I` | `1000 I` | 8 слов как инструкции |

### 6.3. Изменение данных

| Команда | Формат | Описание |
|---------|--------|----------|
| `A = <слово>` | `A = 123456789ABCDEF0` | Записать в СМ |
| `Y = <слово>` | | Записать в РМР |
| `I <N> = <знач>` | `I 7 = 12345` | Записать в индекс-регистр |
| `<адрес> = <слово>` | `1000 = 012 032 1000` | Записать в память |

### 6.4. Точки останова

| Команда | Описание |
|---------|----------|
| `BP <адрес>` | Вкл/выкл точку останова |
| `BPW <адрес>` | Останов при записи в ячейку |

### 6.5. Формат вывода Where

**Обычный режим (trace < 2):**
```
S<адрес>: РР ОП АДР     мнемоника
```

**Расширенный режим (trace >= 2):**
```
S<адрес>: РР ОП АДР     мнемоника
  acc = XXXXXXXX YYYYYYYY Y = ...
```

**Полный режим (trace >= 3):**
```
  M1=12345 M2=12345 M3=12345 ... M15=12345
```

## 7. besmtool — утилита управления дисками

Утилита для создания, модификации и просмотра образов дисков БЭСМ-6.
Исходники: `~/dispak/besmtool/` (besmtool.c, dump.c, erase.c, list.c, passports.c, write.c).

### 7.1. Запуск

```
besmtool <команда> <диск> [опции...]
```

### 7.2. Все команды

| Команда | Синтаксис | Описание |
|---------|-----------|----------|
| `list` | `list [<disk>]` | Список дисковых образов |
| `pass` | `pass [<disk>]` | Просмотр паспортов задач |
| `search` | `search <disk> <pattern>` | Поиск строки на диске |
| `erase` | `erase <disk> [опции]` | Стирание зон (форматом 0x55/0xAA) |
| `zero` | `zero <disk> [опции]` | Обнуление зон (нулями) |
| `view` | `view <disk> [опции]` | Просмотр содержимого с декодированием |
| `dump` | `dump <disk> [опции]` | Дамп содержимого (hex + мнемоника) |
| `write` | `write <disk> [опции]` | Запись данных на диск |
| `check` | `check <disk> [опции]` | Проверка зон на диске |

### 7.3. Опции диапазона зон

| Опция | Описание |
|-------|----------|
| `--start=<zone>` | Начальная зона (восьмеричная) |
| `--last=<zone>` | Последняя зона (восьмеричная) |
| `--length=<nzones>` | Количество зон |

### 7.4. Опции просмотра (view)

| Опция | Описание |
|-------|----------|
| `--encoding=g,k,t,i` | Кодировки декодирования (по умолчанию g,k) |

**Кодировки:**
- `g` — ГОСТ-10859 (основная 6-битная кодировка БЭСМ-6)
- `k` — KOI-7 (для терминалов)
- `t` — Текстовая кодировка мониторной системы Дубны
- `i` — Кодировка автокода ИПМЦЕ (Чайковский)
- `b` — Кодировка БЕМШ
- `f` — Файловый режим (по 1 слову на строку)

### 7.5. Опции записи (write)

| Опция | Описание |
|-------|----------|
| `--from-file=<file>` | Запись из файла |
| `--from-disk=<num>` | Копирование с другого диска |
| `--from-dir=<dir>` | Запись из каталога (формат Морозова) |
| `--from-start=<zone>` | Начальная зона источника |

### 7.6. Опции вывода (dump)

| Опция | Описание |
|-------|----------|
| `--to-file=<file>` | Записать дамп в файл (бинарно) |

### 7.7. Структура данных

- **Зона** = 6144 байт (ZBYTES) = 1024 машинных слова (48 бит = 6 байт)
- **Макс. размер диска** = 010000₈ зон ≈ 25 МБ (MAXZ)
- Файл диска: именуется номером диска (например, `2053`)
- Путь поиска: переменная `BESM6_DISK_PATH` или `--path`

### 7.8. Формат вывода dump

```
ZZZZ.AAAA:  LLLL LLLL RRRR RRRR  llllll rrrrrr  мнемоникаL  мнемоникаR
```
- `ZZZZ` — номер зоны (восьмеричный)
- `AAAA` — адрес в зоне (восьмеричный)
- `LLLL LLLL RRRR RRRR` — левая и правая половины (шестнадцатеричные)
- `llllll rrrrrr` — hex-представление
- `мнемоника` — дизассемблированная команда

### 7.9. Примеры использования

```bash
# Список всех дисков на пути поиска
besmtool list

# Просмотр диска 2053
besmtool list 2053

# Просмотр паспортов задач
besmtool pass 2053

# Просмотр зон 0540-0550 с декодированием ГОСТ+KOI7
besmtool view 2053 --start=0540 --length=020 --encoding=g,k

# Дамп зоны 0677 (СВЯЗЬ7) на диске 2053
besmtool dump 2053 --start=0677 --length=1

# Поиск строки на диске
besmtool search 2053 "СВЯЗЬ7"

# Запись файла на диск (начиная с зоны 0100)
besmtool write 2053 --start=0100 --from-file=my_module.bin

# Обнуление зон 0200-0217
besmtool zero 2053 --start=0200 --length=020

# Стирание зон (формат 0x55/0xAA)
erase 2053 --start=0200 --length=020

# Копирование диска
besmtool write 3000 --from-disk=2053 --start=0 --length=0100

# Дамп зоны в файл
besmtool dump 2053 --start=0677 --length=1 --to-file=zone677.bin

# Декодирование сырого вывода
besmtool view 2053 --start=0543 --length=2 --encoding=g,k,t
```

### 7.10. Работа с форматом Морозова

Утилита `dir_to_disk()` записывает зоны из каталога, где каждая зона
представлена двумя файлами (по 516 слов). Формат используется эмулятором
Морозова. Свертка: левая половина слова XOR правая, бит 0 = нечётность.

```bash
# Запись из каталога Морозова
besmtool write 2053 --from-dir=/path/to/zones/
```

## 8. disbesm6 — дизассемблер

Дизассемблирование бинарных файлов БЭСМ-6.
Исходники: `~/dispak/disbesm6/disbesm6.c`.

### 8.1. Запуск

```
disbesm6 [опции] <файл>...
```

### 8.2. Опции

| Опция | Описание |
|-------|----------|
| `-r` | Длинные команды в правом полуслове |
| `-b` | Вывод в формате БЕМШ (кириллические мнемоники) |
| `-aN` | Начальный адрес (N — восьмеричный) |
| `-eN` | Конечный адрес |
| `-nSymtab` | Файл таблици символов |

### 8.3. Мнемоники

Дизассемблер поддерживает две системы мнемоник:

**Машинный формат (по умолчанию):**
`atx`, `stx`, `mod`, `xts`, `a+x`, `a-x`, `x-a`, `amx`, `xta`, `aax`,
`aex`, `arx`, `avx`, `aox`, `a/x`, `a*x`, `apx`, `aux`, `acx`, `anx`,
`e+x`, `e-x`, `asx`, `xtr`, `rte`, `yta`, `ext`, `e+n`, `e-n`, `asn`,
`ntr`, `ati`, `sti`, `ita`, `its`, `mtj`, `m+j`

**БЕМШ-формат (`-b`):**
`зп`, `зпм`, `рег`, `счм`, `сл`, `вч`, `вчоб`, `вчаб`,
`сч`, `и`, `нтж`, `слц`, `знак`, `или`, `дел`, `умн`,
`сбр`, `рзб`, `чед`, `нед`, `слп`, `вчп`, `сд`, `рж`,
`счрж`, `счмр`, `э32`, `увв`, `слпа`, `вчпа`, `сда`, `ржа`,
`уи`, `уим`, `счи`, `счим`, `уии`, `сли`, `э46`, `э47`

### 8.4. Примеры

```bash
# Дизассемблирование модуля
disbesm6 my_module.bin

# С указанием начального адреса
disbesm6 -a1000 my_module.bin

# В формате БЕМШ
disbesm6 -b my_module.bin

# С таблицей символов
disbesm6 -nsymbols.tab my_module.bin

# Диапазон адресов
disbesm6 -a1000 -e1200 my_module.bin
```

## 9. Память и регистры БЭСМ-6

### 9.1. Организация памяти

- **CORESZ** = 32 клика × 1024 слова = 32768 слов (стандарт)
- **CLICKSZ** = 1024 слов на клик
- **BPW** = 6 байт на слово
- Формат слова: 48 бит (левая половина 24 + правая 24)
- Адресация: 15 бит (0-77777_8)

### 9.2. Специальные ячейки

| Адрес | Назначение |
|-------|------------|
| 0 | Не команда (проверка IS_INSN) |
| `ehandler-11` | АККУМУЛЯТОР (при входе в обработчик) |
| `ehandler-10` | Регистр расширения (enreg) |
| `ehandler-9` | РМР (accex) |
| `ehandler-8` | Адрес возврата (PC) |
| `ehandler-7` | TRAPRETREG |
| `ehandler-6` | addrmod, right |
| `ehandler-5` | Регистр MODREG |
| `ehandler-4` | Регистр М17 |
| `ehandler-3` | Регистр М16 |
| `ehandler-2` | Регистр М15 |
| 062121 | Область IPZ |

### 9.3. Управляющие флаги

| Флаг | Описание |
|------|----------|
| `acc` | Аккумулятор (acc.l, acc.r — два 24-разрядных слова) |
| `accex` | Регистр расширения (Y) |
| `pc` | Счётчик команд |
| `right` | Правая половина слова (0=левая, 1=правая) |
| `reg[N]` | Индекс-регистры (N=1..15, reg[0]=0 всегда) |
| `enab` | Разрешение асинхронных процессов |
| `emask` | Маска событий |
| `events` | Битовое поле событий |
| `ehandler` | Адрес обработчика экстракодов |
| `addrmod` | Режим адресации |

## 13. Типичные сценарии использования

### 13.1. Трансляция БЕМШ-задания

```bash
dispak -p -o listing.txt my_bemsh_task.txt
```

### 13.2. Отладка программы

```bash
dispak -b my_task.txt
# - Where         (текущая позиция)
# - 1000 -        (8 слов с адреса 1000)
# - BP 1200       (точка останова)
# - Go            (продолжить)
# - AD            (СМ как число)
# - I 7 -         (регистр М7)
# - 1200 I        (инструкции)
```

### 13.3. Просмотр содержимого системного диска

```bash
# Паспорты задач на диске 2053
besmtool pass 2053

# Просмотр паспортной зоны
besmtool view 2053 --start=0543 --length=2 --encoding=g,k

# Дамп модуля СВЯЗЬ7 (зона 0677)
besmtool dump 2053 --start=0677 --length=1

# Поиск модуля
besmtool search 2053 "СВЯЗЬ7"
```

### 13.4. Копирование модуля между дисками

```bash
# Копировать зоны 0677-0677 с диска 2053 на диск 3000
besmtool write 3000 --start=0100 --from-disk=2053 --from-start=0677 --length=1
```

### 13.5. Просмотр сырого вывода

```bash
dispak --output-raw=raw.bin -p my_task.txt
dispak --decode-output raw.bin
```

## 14. Отличия dispak от SIMH BESM-6

| Параметр | dispak | SIMH BESM-6 |
|----------|--------|-------------|
| Модель | Интерпретатор команд | Эмуляция аппаратуры |
| Память | 32K слов | 256K слов |
| Терминалы | Нет (stdin/stdout) | tmxr, telnet, VT-340 |
| ДКС/КАДОПАМ | Нет | Эмулируется |
| Диски | Эмуляция зон | Эмуляция НМД |
| Прерывания | Программные (Э50-Э74) | Аппаратные (ПРП, МГРП) |
| Загрузка | Из текстового файла | Из boot_dispak.b6 |
| Конфигурация | Паспорт в задании | dispak.ini + ГЕНС |
| Печать | Эмуляция через Э64 | Файлы линейки |
| Сборка | `cmake + make` | `make besm6` из папки simh |
